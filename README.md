# قالب وردپرس انرژی روشن رامسر

نسخه توسعه‌یافته قالب فارسی و RTL بر اساس رابط کاربری ارائه‌شده.

## ویژگی‌های این نسخه
- فونت **Estedad (استعداد)** برای کل سایت
- طراحی RTL و ریسپانسیو
- صفحه اصلی مطابق طرح
- صفحات داخلی: برنامه خاموشی‌ها، اعلام خرابی، پرداخت قبض، مشاهده قبض، پیگیری درخواست‌ها، اخبار و اطلاعیه‌ها، درباره ما و تماس با ما
- کنترل متن‌های صفحات داخلی از WordPress Customizer
- بخش **تصاویر تمام صفحات** در سفارشی‌سازی برای انتخاب عکس از Media Library
- تصویر هدر، لوگو، تصاویر اخبار، آموزش، نقشه‌ها، صفحه درباره ما و اپلیکیشن قابل انتخاب از رسانه وردپرس

## نصب
1. پوشه قالب را داخل `wp-content/themes/ramser-energy` قرار دهید یا ZIP قالب را نصب کنید.
2. از **نمایش ← پوسته‌ها** قالب را فعال کنید.
3. به **نمایش ← سفارشی‌سازی ← تنظیمات سایت برق رامسر** بروید.
4. متن‌ها و تصاویر را تنظیم کنید.
5. برای صفحات داخلی، Pageهایی با slugهای زیر بسازید تا قالب‌های خودکار WordPress آن‌ها را تشخیص دهند:
   - `program-outage`
   - `report-outage`
   - `bill-payment`
   - `bill`
   - `request-tracking`
   - `news`
   - `about`
   - `contact`

## بخش تصاویر
در **تنظیمات سایت برق رامسر ← تصاویر تمام صفحات** می‌توانید برای تمام جایگاه‌های تصویری، عکس دلخواه خود را از کتابخانه رسانه انتخاب کنید. اگر عکس انتخاب نشده باشد، قالب جایگاه راهنما نمایش می‌دهد.

## نکته فنی
این نسخه برای UI و ساختار قالب آماده است. فرم‌های پرداخت، اعلام خرابی، پیگیری و داده‌های خاموشی فعلاً رابط کاربری هستند و برای اتصال به API/سامانه‌های واقعی باید endpoint و منطق سرویس مربوطه اضافه شود.
