# قالب وردپرس انرژی روشن رامسر

این مخزن شامل یک قالب RTL فارسی وردپرس برای تبدیل رابط کاربری ارائه‌شده به قالب واقعی وردپرس است.

## نصب
1. مخزن را Clone کنید یا ZIP بگیرید.
2. پوشه را داخل `wp-content/themes/ramser-energy` قرار دهید.
3. قالب را از **نمایش ← پوسته‌ها** فعال کنید.
4. وارد **نمایش ← سفارشی‌سازی ← تنظیمات سایت برق رامسر** شوید.
5. متن‌ها، لوگو و تصویر هدر را از همان بخش تغییر دهید.

## قابل ویرایش از سفارشی‌سازی
- نام سازمان، زیرعنوان، شماره تماس و متن جستجو
- تمام متن‌های هدر اصلی و دکمه
- ۶ کارت خدمات و توضیحات آن‌ها
- عنوان و توضیحات وضعیت برق
- ۳ اطلاعیه
- تمام اعداد و برچسب‌های آماری
- عنوان و آیتم‌های بخش آموزش و اخبار
- عنوان و توضیحات اپلیکیشن
- تمام متن‌های فوتر و اطلاعات تماس
- لوگو
- تصویر پس‌زمینه هدر

## ساختار
- `style.css` — استایل RTL، واکنش‌گرا و ظاهر اصلی
- `functions.php` — ثبت قالب و کنترل‌های WordPress Customizer
- `header.php` — سربرگ و منوی اصلی
- `front-page.php` — صفحه اصلی
- `footer.php` — پابرگ قابل تنظیم
- `index.php` — قالب fallback وردپرس

## نکته
برای تطابق تصویری کامل با طرح، تصویر واقعی پس‌زمینه رامسر را در **سفارشی‌سازی ← صفحه اصلی - هدر اصلی ← تصویر پس‌زمینه هدر اصلی** آپلود کنید. قالب بدون Elementor و با PHP/Customizer خود وردپرس کار می‌کند.
